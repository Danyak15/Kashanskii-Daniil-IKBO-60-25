# Практическая №2 — Граф зависимостей npm

Программа на Kotlin для анализа зависимостей npm-пакетов. Получает данные из npm Registry через HTTP, строит граф алгоритмом BFS без рекурсии, учитывает циклы и максимальную глубину.

Поддерживает тестовый режим, вывод порядка обхода, Graphviz DOT, PNG и ASCII-дерево.

## Требования

JDK 21, Graphviz (`dot` должен быть доступен в PATH). Для работы с npm Registry необходимо подключение к интернету.

## Запуск

Из каталога `practice2`:

- Запуск: `.\run.bat`
- Тестирование: `.\gradlew.bat clean test`

## Конфигурация

Параметры задаются в `config.yaml`.

| Параметр          | Описание                                       |
|-------------------|------------------------------------------------|
| `package_name`    | Имя анализируемого пакета                      |
| `repository`      | Адрес npm Registry или путь к тестовому файлу  |
| `test_mode`       | Использовать тестовый файл вместо npm Registry |
| `version`         | Версия исходного пакета                        |
| `ascii_tree`      | Выводить ASCII-дерево                          |
| `max_depth`       | Максимальная глубина обхода                    |
| `show_load_order` | Выводить порядок обработки или HTTP-запросов   |

В тестовом режиме используются графы из файла `tests/fixtures/graph.txt` с названиями пакетов из заглавных латинских букв.

## Результаты

Программа выводит зависимости в консоль, сохраняет `build/dependencies.dot` и `build/dependencies.png`, после чего открывает изображение графа.

## Примеры

Проверены три пакета: `express@4.18.2`, `accepts@1.3.8`, `debug@2.6.9`.

Для тестового графа используются `package_name: "A"`, `test_mode: true` и `repository: "tests/fixtures/graph.txt"`.

## Сравнение с npm

Граф Express сравнивался с результатом `npm ls --all --depth=3`. Основные связи зависимостей совпали.

Отличия объясняются тем, что программа использует упрощённый выбор версий и объединяет одинаковые имена пакетов, а npm поддерживает несколько версий одного пакета. Порядок HTTP-запросов также может отличаться из-за параллельной загрузки и кэширования в npm.
