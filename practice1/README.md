# EmulatorOS

Эмулятор командной строки UNIX-подобной ОС на Kotlin с графическим интерфейсом Swing. Реализованы первые три этапа практической работы, вариант №14.

Программа поддерживает команды `ls`, `cd` (заглушки), `exit` и `vfs-init`. Виртуальная файловая система загружается из CSV и хранится в оперативной памяти. Содержимое файлов кодируется в Base64.

## Запуск

Требуется JDK 21.

Сборка проекта:

```powershell
.\gradlew.bat build
```

Обычный запуск:

```powershell
.\run.bat
```

## Проверка

| Команда                    | Назначение                     |
|----------------------------|--------------------------------|
| `.\run-vfs-minimal.bat`    | Минимальная VFS                |
| `.\run-vfs-files.bat`      | Несколько файлов               |
| `.\run-vfs-init.bat`       | Сброс VFS                      |
| `.\run-vfs-all.bat`        | Проверка всех команд           |
| `.\run-errors.bat`         | Неизвестные команды            |
| `.\run-missing-script.bat` | Отсутствующий стартовый скрипт |

## Параметры

Эмулятор принимает два аргумента: путь к CSV-файлу VFS и путь к стартовому скрипту.

```powershell
.\gradlew.bat run --args="data/vfs.csv scripts/startup.txt"
```

Команда `vfs-init` очищает виртуальную файловую систему в памяти и соответствующий CSV-файл. Для безопасной проверки используются временные копии CSV.
